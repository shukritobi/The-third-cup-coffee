# The 3rd Cup website concept

A responsive one-page website concept for **The 3rd Cup** (`@thethirdcup.my`).

## Included

- Mobile-first landing page
- Featured drinks and soft-launch positioning
- Event and collaboration enquiry flow
- Instagram and Threads links
- Service-area content for Cyberjaya, Putrajaya and Dengkil
- Basic SEO metadata and LocalBusiness structured data

## Preview with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, then select **main** and **/(root)**.

The expected URL is:

`https://shukritobi.github.io/The-third-cup-coffee/`

## Before final launch

Replace the stock images with the business's own product photos, add the confirmed menu and prices, and insert the official WhatsApp number if the owner wants direct WhatsApp ordering.
